# Profit Pet Workflow

Profit Pet is a MAH use case, not a standalone promise that a pet already earns money.

The story is:

```text
personal pet -> money project scout -> route map adapter -> MAH execution
```

## 1. Pet Layer

The user imports a pet photo and gets a small floating desktop pet.

This layer creates attention and emotional ownership. The user is not looking at another dashboard; they are looking at "my pet found something that might pay me back."

## 2. Opportunity Source Layer

The pet can read from multiple opportunity sources.

OSS Goldmine remains useful, but it is only one source:

- OSS Goldmine for developer-tool opportunities.
- Writing markets for fiction, essays, scripts, and paid content.
- Digital product markets for templates, reports, and small tools.
- Service markets for tasks that can be packaged into paid gigs.
- Trend signals for topics with current attention.

## 3. Money Project Adapter

The adapter turns a raw opportunity into a testable money project:

- what to sell
- who might pay or read
- first version scope
- first 48-hour test
- non-goals
- risk
- proof needed

This is the bridge from "interesting idea" to "work MAH can keep pushing."

## 4. MAH Route Map

The route map is currently an abstract handoff format.

When MAH is available, this should become a real route map plus scheduled tasks:

- daily project progress
- source-specific research
- agent-specific production tasks
- outreach or publishing loop
- feedback summary
- next-step recommendation

## What The Demo Should Prove

The demo should prove that the story is understandable:

```text
The pet found a realistic money-making project.
The project can become a plan.
The plan can become a MAH route map.
MAH is the system that keeps pushing after the user stops watching.
```
