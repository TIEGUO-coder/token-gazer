# MAH Route Map Example

Project: AI resource pack shop

Source: Money project scout

## Goal

Turn one small digital product idea into a 48-hour earning test: research a niche, make a useful resource pack, publish a simple page, and collect interest signals.

## Why This Needs MAH

This is not a single prompt task.

It needs recurring research, content production, packaging, publishing, signal tracking, and weekly iteration. MAH is useful because it can keep the work moving across multiple agents after the user stops watching.

## Phase 1: Find A Specific Paid Need

Tasks:

- Research 5 niches where people pay for time-saving templates or reports.
- Pick one niche with a concrete buyer and urgent pain.
- Write the product promise in one sentence.
- Define the first version scope and non-goals.

Suggested agents:

- Research agent for demand signals.
- Strategy agent for niche selection.

## Phase 2: Produce The Resource Pack

Tasks:

- Draft the checklist, template, report, or prompt kit.
- Design a simple cover and preview.
- Package files for download.
- Write a short landing page or README.

Suggested agents:

- Writing agent for the pack.
- Design agent for preview assets.
- Codex for page, repo, or download packaging.

## Phase 3: Publish And Track Signals

Tasks:

- Publish to one channel.
- Record clicks, saves, replies, waitlist signups, or payment attempts.
- Summarize objections and missing information.
- Recommend continue, narrow, or stop.

Suggested agents:

- Publishing agent for channel formatting.
- Analyst agent for signal summary.

## Scheduled Tasks

Daily:

- Check feedback signals.
- Recommend one concrete next action.
- Update the route map with what changed.

Weekly:

- Re-score the project.
- Decide whether to continue, revise, or stop.
- Pick the next distribution test.

## MAH Handoff

Current state:

- This file is an abstract route map.

Future state:

- MAH converts this route map into scheduled tasks, multi-agent assignments, and recurring progress reports.
